- Package:
  psm_PageObjects.salesforce;
- Class name:
  POM class name MUST be derived from:

  Current Test Step Label
  Example:

  Label: Languages

  Class Name: RegisterPage
  File Name: RegisterPage.java

- Class declaration:
- Imports:
  Include only required imports.
  Always include:

  import net.serenitybdd.core.*;
  import net.serenitybdd.core.pages.PageObject;
- Driver declaration:

  Replace ClassName with the actual generated class name.
- Locators:
  Create all locators as global class-level variables.
  Do not create locators inside methods.
- Methods:
  Create one method for each action described in the Test Steps.
  Method names should be meaningful and business-readable.
  MANDATORY CONSTRUCTOR (DO NOT SKIP):
  Every generated POM class MUST contain a constructor.
  Constructor format:

        this.driver = getDriver();
    }
- Selenium interactions:
  Use SeleniumUtils methods only for all page interactions.
  Do not use driver.findElement(), click(), sendKeys(), getText(), Select, Actions, JavaScriptExecutor, or explicit Selenium actions directly.

- Design rules:
  - Follow Page Object Model design.
  - Keep methods reusable.
  - Use descriptive locator names.
  - Avoid duplicate methods.
  - Generate only page-specific methods.
  - Do not include test logic, assertions, or validations in POM classes.
- Allowed SeleniumUtils methods:
    click(WebDriver driver, By locator)
    type(WebDriver driver, By locator, String text)
    getText(WebDriver driver, By locator)
    selectByVisibleText(WebElement dropdown, String visibleText)
    hoverOverElement(WebDriver driver, By locator)
    scrollintoView(WebDriver driver, WebElement element)
    clickViaJS(WebDriver driver, WebElement element)
    waitForAlert(WebDriver driver, long timeoutSec)
    acceptAlert(WebDriver driver)

    getAlertText(WebDriver driver)
    getAllOptionsText(WebElement dropdown)
    isTextPresent(WebDriver driver, String text)
    isElementDisplayed(WebDriver driver, By locator)
